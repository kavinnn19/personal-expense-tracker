# Personal Expense Tracker

A simple Personal Expense Tracker built with Python and Streamlit.

## Features

- Add new expenses
- View all expenses
- Search expenses
- Filter expenses by category
- Delete expenses
- Calculate total spending
- Calculate category-wise spending
- Store expenses in a CSV file
- Automated testing using pytest

## Technologies Used

- Python
- Streamlit
- CSV
- pytest
- Git and GitHub
